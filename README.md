# VOID

A top-down arcade survival shooter. Endless waves, escalating enemies,
and a boss every 10 waves. Dark galaxy, gore aesthetic.

**▶ Play:** https://r0ck574r.github.io/void/

## Controls
- WASD / Arrows — Move
- Mouse — Aim & auto-fire
- Space — Pulse blast
- P — Pause · M — Sound

## Tech
Single-file HTML5 canvas. No dependencies, no build step.
Synthesized audio via Web Audio API.
